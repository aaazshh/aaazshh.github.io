Work

Logistics platform

A multi-company logistics system built from scratch in plain PHP 7.4, vanilla JS, and MySQL, no framework. Admins manage fleets and drag-and-drop vehicle assignments across companies, drivers get routes on a Leaflet map with OSRM-based route optimisation, and a public tracking page lets customers follow a delivery without logging in. Bulk order intake happens through an Excel import pipeline (Prime Online orders) that geocodes addresses and assigns trucks automatically.

  • PHP 7.4
  • MySQL
  • Vanilla JS
  • Leaflet.js
  • OSRM
  • Chart.js

Logistics, mobile

The driver-facing side of the logistics platform. Built in Flutter, it pulls active routes from the PHP backend over a bearer-token REST API, renders turn-by-turn stops with flutter_map, and reports GPS position back so admins can watch deliveries move in real time.

  • Flutter
  • flutter_map
  • REST API

Fish farm operations portal

A daily-operations tool for fish farm staff to log harvests, feed and medicine inventory, environment surveys, net changes and repairs, and incidents, replacing what used to be paper logs. Role-based access for admins vs. staff, built on a shared internal auth pattern used across the company's other portals.

  • PHP
  • MySQL
  • Bootstrap 5

Fish farm, mobile

Flutter companion app so farm staff can log the same operational data from the field instead of walking back to a desktop.

  • Flutter

IAM / SSO service

The identity layer other internal portals plug into: single sign-on, role and department mapping, and per-portal access control, so logging into one company system logs you into the rest without re-authenticating.

  • PHP
  • MySQL
  • SSO

Analytics tooling

Report generation and data automation: Elasticsearch-backed indexing for fast lookups, PHPSpreadsheet for Excel exports like ABC analysis and vendor commission reports, and headless-browser scraping with Puppeteer for data sources without an API.

  • PHP
  • Elasticsearch
  • Node.js
  • Puppeteer

HQ platform, web & mobile

The company's internal HQ admin system, a Laravel app on the backend with a Tailwind/Vite front end, paired with a Flutter mobile app for the same workflows on the go.

  • Laravel
  • Tailwind CSS
  • Flutter
